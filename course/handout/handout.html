L0 · Orientation notebook ch00

What LAMMPS is, its two release lines, the install routes this project measured, and how record-or-run lets every chapter run with or without LAMMPS installed.

Key ideas

  • LAMMPS is a classical molecular dynamics engine maintained by Sandia/NTESS: you write an input script, it integrates Newton's equations for a box of particles under a chosen potential.
  • LAMMPS ships two lines from the same repository, and a distribution package usually tracks one without saying so.
  • lammpskill is the part of this project that talks to LAMMPS -- five pieces behind one import.
  • mdlite is a small molecular-dynamics engine written from scratch in numpy -- a teaching object, not an MD code; nobody should run research on it.
  • The most common way to be wrong about a LAMMPS build is to assume a bigger package set is a superset.

L1 · First Simulation notebook ch01

A Lennard-Jones melt end to end -- Spec, check, run, read the log, plot -- through the checker's fourteen rules, one at a time.

Key ideas

  • Spec describes the case in Python; check applies fourteen rules against the manual before anything runs; run calls LAMMPS; the log comes back as a typed ThermoRun.
  • lammpskill.script.check() does not trust a description of what a mistake looks like -- each rule is confirmed against one minimal snippet built to trigger exactly it.
  • The chapter does not just list the rules -- it runs all fourteen deliberately-broken snippets through the checker and confirms every one is caught.
  • lammpskill.script.lj_melt() is a preset Spec: reduced units, an FCC lattice at the melt density rho=0.8442, 4000 atoms by default. render() turns it into the actual input text, in the order the manual's Commands_structure page prescribes.
  • Every step so far -- the fourteen checks, the rendered script, the thermo curves -- was about this: real atoms, in a real box, moving under a real force law.

L2 · Forces and Integration notebook ch02

Velocity Verlet in mdlite, forces checked against a numerical derivative, and energy conservation against the timestep, cross-checked with LAMMPS at 3e-13.

Key ideas

  • mdlite implements velocity Verlet from the same equations LAMMPS integrates, so its forces can be checked against a numerical derivative and against LAMMPS itself.
  • Before trusting an integrator, check the thing it integrates: displacing one atom by h and taking the central difference of the energy should reproduce the analytic force component.
  • A correct integrator's energy drift shrinks as the timestep shrinks -- roughly as dt^2 for velocity Verlet. Running the same starting state at two timesteps for the same physical time makes that concrete.
  • The comparisons above stay inside mdlite. data/records/lj_energy_vs_lammps.json asks the same question across the boundary: 256 atoms, the same Lennard-Jones potential, forces from mdlite compared to forces LAMMPS itself printed to a dump.

Equations

  • Fk ≈ -(E(xk+h) - E(xk-h)) / 2h — central difference
  • v(t+Δt/2) = v(t) + (Δt/2) a(t) — half-kick
  • x(t+Δt) = x(t) + Δt·v(t+Δt/2) — drift
  • v(t+Δt) = v(t+Δt/2) + (Δt/2) a(t+Δt) — second half-kick

L3 · Thermostats notebook ch03

Berendsen, Langevin and a Nose-Hoover chain: what each one conserves, what each distorts, and NVT checked against the NIST reference within 3 sigma.

Key ideas

  • A thermostat couples the system to an external bath; which one you choose changes what else it disturbs.
  • Each way of holding a temperature trades something different -- visible on the same axes in the figure just shown, not taken on faith.
  • The chain adds an extended-system energy H_extra; the total H = E_tot + H_extra should stay flat if the half-step bookkeeping is right, independent of whether the temperature looks reasonable.
  • data/records/lj_nvt_nist.json compares mdlite's equilibrium pressure and energy at one NIST reference state point to the NIST Standard Reference Simulation Website's own table.

Equations

  • H = Etot + Hextra — conserved quantity
  • λ = √(1 + (Δt/τ)(T₀/T − 1)),   v → λv — velocity scaling

L4 · Ensembles and Restarts notebook ch04

An NPT sketch with its limits stated, LAMMPS's own fix npt, and restarting a run through write_restart / read_restart.

Key ideas

  • NPT couples a barostat to the thermostat so the box itself relaxes toward a target pressure; restarting means LAMMPS can continue a run exactly, not merely resume from the last log line.
  • LAMMPS's fix npt couples a Nosé–Hoover chain on both temperature and pressure -- a real fluctuating-cell method, not a weak-coupling sketch.
  • read_restart defines the box -- and LAMMPS refuses a units command once the box exists (hit live while writing this chapter: ERROR: Units command after simulation box is defined).
  • Stage A runs 300 steps and checkpoints; stage B reads that checkpoint and runs 300 more -- as if it never stopped.

Equations

  • μ = (1 − (Δt/τ)·χ·(P₀ − P))1/3,   L → μL — box scaling

L5 · Potentials: EAM notebook ch05

An embedded-atom potential read from a real setfl file: copper's lattice constant and cohesive energy against the recorded 3e-5 -- and why the potential file is never shipped.

Key ideas

  • The embedded-atom method adds a density-dependent term to a pairwise potential -- realistic enough for metals, and never something this project ships.
  • The embedded-atom method adds a term that depends on the local electron density to an otherwise ordinary pairwise potential.
  • mdlite.eam.EAM's forces should match a numerical derivative of its energy on any potential, real or synthetic -- the identical discipline L2 applied to Lennard-Jones.
  • Place an FCC lattice at a grid of lattice constants, compute the energy per atom at each, fit a cubic, take the minimum -- the method this toolkit uses for any EAM element.
  • The same fit gives one more property: remove the lattice site nearest the supercell's centre and relax the rest with FIRE (L7's other minimiser) -- the perfect supercell (left) and the relaxed vacancy configuration (right).

Equations

  • E = Σi F(ρi) + ½ Σi≠j φ(rij) — total energy
  • ρi = Σj≠i ρ(rij) — local density

L6 · Structure and Analysis notebook ch06

Radial distribution function, structure factor, mean-squared displacement, diffusion coefficient and velocity autocorrelation, computed from one trajectory.

Key ideas

  • A dump file is a sequence of raw coordinates; lammpskill.post turns it into the quantities a paper would actually report.
  • The structure factor is the same structural information as the radial distribution function, in reciprocal space -- literally derived from it, in this toolkit and in general.
  • Fitting D from the whole MSD(t) curve is a common way to get a confidently wrong number.
  • block_average splits a correlated time series into blocks, averages within each, then takes the standard error across blocks -- correlated samples inside one block do not inflate the apparent precision.

Equations

  • S(k) = 1 + 4πρ ∫0∞ r² (g(r) − 1) sinc(kr) dr — isotropic structure factor
  • D = limt→∞ MSD(t) / 6t — Einstein relation (3D)

L7 · Minimisation notebook ch07

Steepest descent against FIRE on an LJ wall -- and the lesson that gives lost atoms their name: an uncapped step explodes at fmax 2.6e14.

Key ideas

  • The single largest category of beginner questions on the LAMMPS forum is lost atoms and nan energies (docs/08) -- this chapter reproduces the mechanism directly.
  • Two atoms at r=0.3 sigma, deep in the Lennard-Jones repulsive core -- the potential's minimum is near r=2^(1/6) sigma ~= 1.12, so the force here is enormous.
  • A displacement cap does not change what force is computed -- it only limits how far a single step is allowed to move an atom in response to it.
  • A perturbed FCC lattice -- every atom nudged off its site -- is more representative than the pathological two-atom case.

Equations

  • Δx = αF — proposed step
  • α·fmax > dmax ⇒ Δx ← Δx · (dmax / αfmax) — the cap

L8 · Reading What LAMMPS Writes notebook ch08

Data, dump, log and restart formats, and four pitfalls this project hit first: thermo normalisation, dump precision, the restart magic number, multi-format logs.

Key ideas

  • Every format LAMMPS writes has one behaviour that looks like a bug the first time you meet it.
  • Every parser in lammpskill/io/ was written from the manual's description of the format plus files LAMMPS actually wrote on this machine.
  • The very first LJ cross-check compared -6.04 (LAMMPS) with -1545.7 (mdlite) for the same 256 atoms -- nothing was wrong with either number.
  • The restart magic string is the 15 printable characters LammpS RestartT -- but LAMMPS writes it as a 16-byte NUL-terminated field on disk.

L9 · Choosing a Build notebook ch09

What a 314-case sweep of the examples says: package list beats package count, and how to read Installation.packages before choosing styles.

Key ideas

  • A 314-case sweep of LAMMPS's own example scripts, run on this project's two installed builds, is the evidence behind this lecture.
  • Every case is scored from its log, never its exit status -- LAMMPS exits 0 after a fatal input error (N-15), so the exit code alone would call failures successes.
  • bench/'s five canonical cases ship a reference log from the LAMMPS developers themselves -- the sweep's numbers here are exact-match or explained, not merely close.
  • ML-SNAP, ML-IAP, AMOEBA, REAXFF and MDI are missing from both builds -- exactly the machine-learning and reactive packages this project staged for later.

L10 · Scaling and Limits notebook ch10

MPI and OpenMP speed-up on eight cores, where it stops, and what this machine honestly cannot do -- no GPU, no -partition methods.

Key ideas

  • Measured on this project's 8-core, no-GPU machine: 2 MPI ranks gave 1.73x, 2 OpenMP threads gave 2.09x -- both honestly short of ideal.
  • Same case as L1 (4000 atoms), 1000 steps so start-up does not dominate the timing signal; this session was allowed 2 CPU cores under this project's compute-sharing policy.
  • This system is small and the run is short, so per-rank overhead -- domain decomposition, communicating the boundary between two halves of a small box -- is a real fraction of the total time, not a rounding error.

L11 · Polymers notebook ch11

A bead-spring chain -- harmonic bonds and full Lennard-Jones, mdlite against LAMMPS to round-off -- and watching it collapse from a straight line into a globule.

Key ideas

  • The field-standard bead-spring polymer model (Kremer & Grest 1990) uses FENE bonds and WCA (purely repulsive) Lennard-Jones so chains cannot cross themselves. mdlite has neither -- only HarmonicBond and full Lennard-Jones, already used everywhere else in this course.
  • The two potentials this chapter's model is built from -- both already implemented in mdlite, neither new.
  • LAMMPS excludes directly-bonded pairs from its nonbonded sum by default -- invisible unless you know to look, and exactly wrong for a cross-check against a potential with no exclusion concept at all.
  • The starting conformation (left) and the same chain animated across a real 2000-step run (right) -- full Lennard-Jones makes a homopolymer collapse into a compact globule rather than wander as an extended coil.

Equations

  • Ebond = k(r - r0)² — harmonic bond
  • ELJ = 4ε[(σ/r)12 - (σ/r)6] — Lennard-Jones

Glossary

LJ units
LAMMPS's reduced (Lennard-Jones) unit system: energy, length and mass are in units of the potential's own epsilon, sigma and particle mass, so every quantity is dimensionless.
record-or-run
This project's pattern for a chapter cell that needs LAMMPS: with an installation detected, it runs and records the result; without one, it loads a previously recorded result instead.
thermostat
A method that couples a simulated system to an external heat bath so it samples a chosen temperature instead of drifting under its own dynamics.
ensemble
The statistical set a simulation samples from -- NVE (fixed energy), NVT (fixed temperature), NPT (fixed temperature and pressure) -- named by what is held fixed.
EAM
Embedded-atom method: a potential for metals that adds an energy depending on the local electron density, on top of a pairwise term.
RDF / g(r)
Radial distribution function: the probability of finding another particle at distance r, relative to a uniform (ideal-gas) density.
MSD
Mean-squared displacement: the average squared distance particles have moved after time t; its late-time slope gives the diffusion coefficient.
checker
lammpskill's fourteen-rule static check of a generated input script against the LAMMPS manual, run before any script reaches LAMMPS.
